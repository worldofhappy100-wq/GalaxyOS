# GalaxyOS
Modular operating system for CC:Tweaked

This repository hosts the versioned add-on packages for Galaxy OS. In Galaxy Store, open **Filters → Refresh catalog** to discover packages. Each version includes a manifest and Lua files. The Store checks the file paths, byte lengths and SHA-256 digests before installing.

See [the package and Turtle client guide](docs/packages.md) for the layout, install commands and Robotics setup.
