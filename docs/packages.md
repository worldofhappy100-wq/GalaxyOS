# Пакеты Galaxy OS

Galaxy Store хранит программы в `/galaxy/packages/<id>/`. Файлы ядра остаются в `/galaxy/`. Удаление пакета освобождает его каталог и оставляет данные в `/galaxy/users/` и `/galaxy/config/`.

В окне Store выберите пакет и действие Install, Reinstall, Update или Remove. Закройте приложение прежде, чем меня́ть его пакет. Список Installed доступен через Filters. Refresh catalog скачивает проверенный по структуре каталог и сохраняет его в конфигурации. Требуется, чтобы настройка HTTP CC:Tweaked разрешала прямой HTTPS-запрос к `raw.githubusercontent.com`. Установленные пакеты запускаются с диска.

## Структура репозитория

```text
catalog.json
apps/<id>/<version>/manifest.json
apps/<id>/<version>/main.lua
games/<id>/<version>/manifest.json
games/<id>/<version>/main.lua
docs/
```

У пакета есть идентификатор, версия, категория, имя, описание, иконка, точные версии зависимостей и список файлов. Для каждого файла манифест содержит относительное имя, размер, SHA-256 и полный URL. Файлы одной версии публикуются по постоянным путям. При изменении кода создаётся новая папка версии. В каталог попадает актуальная версия. Старые версии можно оставлять в репозитории.

Ядро принимает допустимые имена в одном каталоге пакета, сверяет длину и SHA-256 перед переносом из временного каталога, проверяет требуемые версии и не выполняет Lua до запуска приложения. Контрольная сумма проверяет соответствие файлу из каталога. Доверие к каталогу и коду обеспечивается доступом на запись в GitHub-репозиторий и защищённым HTTP-соединением. Скачанное приложение работает с правами запущенного компьютера.

Файлы `game2048`, `minesweeper` и `breakout` устанавливаются отдельно. Их запускает общий пакет Games. Удалите зависимые игры прежде, чем удалить сам Games. Установка одной игры при необходимости добавит Games.

Для сборки используйте `python3 tools/catalog.py`. Ключ `--offline` также создаёт содержимое `galaxy/packages/` для первой установки без интернета.

## Robotics

Скопируйте `turtle_client.lua`, `protocol.lua` и `sha256.lua` из одной версии Robotics в общий каталог на Turtle, подключите модем и запустите `turtle_client <ID компьютера с Galaxy OS>`. Задайте уникальную фразу из 8–64 символов. В Galaxy OS откройте Robotics, нажмите Pair, введите ту же фразу и выберите найденную Turtle. Фраза хранится в памяти до завершения работы.

Команды программы доступны из каталога `/robotics-programs/` на Turtle. Скопируйте туда доверенный Lua-файл и подтвердите его запуск в контроллере. Для остановки программы с длительным выполнением используйте консоль Turtle. Сведения о состоянии, топливе и инвентаре поступают по rednet.
